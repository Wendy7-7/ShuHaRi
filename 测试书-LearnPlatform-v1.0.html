明确不在测试范围（别浪费时间）

  • 多窗口、插件、云同步：不存在，也不用测
  • 非 Windows 系统：不支持
  • AI 回答内容质量：取决于测试者自备的模型和 Key，只测流程通不通，不评判回答好坏
  • 签名/杀毒误报：无代码签名证书是已知事实，SmartScreen 提示属预期行为

二、测试环境

  1. Windows 10 1803+ / Windows 11（WebView2 自带）
  2. 两个版本各测一遍：
    • 桌面版：桌面 LearnPlatform.exe（数据存 %APPDATA%\com.wendi.learn-platform）
    • 便携版：learn-platform\portable\ 整个文件夹（数据存 portable\Data）
  3. AI 用例需要测试者自备任意一家 OpenAI 兼容 API Key（DeepSeek / 智谱 / Kimi 均可，设置页有预设）
  4. 建议先用干净状态测：删掉 Data 目录 / %APPDATA%\com.wendi.learn-platform 下的 learn.db*，即可重置为全新用户
