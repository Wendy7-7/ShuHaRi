# 第 1 课：折线图与柱状图（Day 1）

目标：根据问题选对图，而不是把每种图都画一遍。

## 1.1 什么时候用哪一种

| 问题 | 图 | 例子 |
|---|---|---|
| 随时间怎么变 | 折线图 | 历年平均分变化 |
| 不同类别谁高谁低 | 柱状图 | 各学校平均分比较 |
| 两个变量有没有关系 | 散点图 | 学习时长与得分 |
| 两个量纲要放一起 | 双 Y 轴 | 平均分与队伍数 |

**美赛用在哪**：折线常见于趋势与预测，柱状常见于方案对比，散点常见于相关关系。
图表类型服务于问题，不服务于"显得丰富"。

## 1.2 折线图：历年平均分

数据 `mcm/matplotlib_kit/data/year_trend.csv`：

```text
year,avg_score,teams
2024,81.0,5
2025,81.2,5
2026,76.0,6
```

新建 `line_chart.py`：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("mcm/matplotlib_kit/data/year_trend.csv")

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(df["year"], df["avg_score"], marker="o", label="Average score")

ax.set_title("Average score by year")
ax.set_xlabel("Year")
ax.set_ylabel("Average score (points)")
ax.set_xticks(df["year"])
ax.set_ylim(0, 100)                    # 分数有明确上限，统一 0–100 更诚实
ax.legend()

fig.tight_layout()
fig.savefig("figures/year_line.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

运行后检查：标题、两个轴名称、单位、圆点、图例都在。

### 为什么设置 ylim(0,100)

如果只显示 75–82 分，81.2 到 76.0 的下降会在视觉上被拉得特别夸张。
**截断坐标轴不一定错，但必须是有意选择，并能解释。**
分数有 0–100 的天然范围，本练习统一用完整范围。

## 1.3 柱状图：学校平均分比较

数据 `mcm/matplotlib_kit/data/school_summary.csv`：

```text
school,avg_score,teams
XJTLU,81.86,7
HIT,81.67,3
SJTU,81.00,2
NUAA,71.75,4
```

新建 `bar_chart.py`：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("mcm/matplotlib_kit/data/school_summary.csv")
df = df.sort_values("avg_score", ascending=False)

fig, ax = plt.subplots(figsize=(7, 4))
bars = ax.bar(df["school"], df["avg_score"], label="Average score")

ax.set_title("Average score by school")
ax.set_xlabel("School")
ax.set_ylabel("Average score (points)")
ax.set_ylim(0, 100)
ax.bar_label(bars, fmt="%.2f")          # 柱顶显示数值
ax.legend()

fig.tight_layout()
fig.savefig("figures/school_bar.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

`sort_values` 让柱子从高到低排列，读者不用自己排序。
`bar_label` 让准确数值直接显示，不必靠眼睛读高度。

## 1.4 图例不是每张图都必须有

只有一组数据、且标题已经说清楚时，图例可以删掉：

```python
# ax.legend()  # 单系列且标题清楚时可以不要
```

本课程为了练 `label` 和 `legend` 先保留。
论文中如果每张单系列图都写一个 "Average score" 图例，反而显得模板化。

## 1.5 把数据标签和样本量一起呈现

平均分高不代表差异可靠。可以在 X 轴类别里带上队伍数：

```python
labels = df["school"] + " (n=" + df["teams"].astype(str) + ")"
ax.bar(labels, df["avg_score"])
```

这样 XJTLU 会显示为 `XJTLU (n=7)`，SJTU 为 `SJTU (n=2)`。
**美赛论文里，样本量信息往往比漂亮的配色更加分。**
