## 3.1 标注最高点

使用 `data/team_scores.csv`，先筛选 C 题：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("data/team_scores.csv")
top = df.loc[df["score"].idxmax()]

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(df["year"], df["score"], label="Teams")

ax.annotate(
    f"Highest: {top['team_id']} ({top['score']} points)",
    xy=(top["year"], top["score"]),
    xytext=(2024.3, 93),
    arrowprops={"arrowstyle": "->"}
)

ax.set_title("Team scores by year")
ax.set_xlabel("Year")
ax.set_ylabel("Score (points)")
ax.set_xticks(sorted(df["year"].unique()))
ax.set_ylim(0, 100)
ax.legend()

fig.tight_layout()
fig.savefig("figures/annotated_scores.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

### annotate 的三个关键部分

```python
ax.annotate(
    "显示的文字",
    xy=(点的位置),          # 箭头指向哪里，用数据坐标
    xytext=(文字的位置),     # 文字放在哪里，也是数据坐标
    arrowprops={"arrowstyle": "->"}
)
```

本数据最高分为 T13，2026 年，95 分。
如果箭头遮住其他点，就调整 `xytext`，不要硬塞在原位置。

## 3.2 加参考线

```python
ax.axhline(80, linestyle="--", linewidth=1, color="gray", label="80-point reference")
ax.legend()
```

`axhline` = 水平参考线；`axvline` = 垂直参考线。
美赛里常用于阈值、目标值、基准方案。

参考线也必须进图例，不然一条虚线会让读者猜。

## 3.3 论文图的六项检查

每张图保存后，逐项检查：

- [ ] 标题说的是内容，不是 "Figure 1" 或 "Result"
- [ ] X/Y 轴都有名称
- [ ] 有单位的都写单位（points、h、teams、%）
- [ ] 多系列有图例，参考线也有图例
- [ ] 关键点有标注或数据标签，避免读者猜数值
- [ ] 正文有一句图后分析，不是把图扔进去就结束

### 正文怎么写

弱写法：

> The results are shown in Figure 2.

合格写法：

> Figure 2 shows that XJTLU has the highest mean score (81.86, n=7),
> while NUAA has the lowest (71.75, n=4). However, the small sample
> sizes limit the strength of this comparison.

**图负责展示，正文负责解释，两者不能互相替代。**

## 3.4 不要做的事

1. 不要 3D 柱状图：只会增加读取难度
2. 不要彩虹色：颜色用来区分系列，不是装饰
3. 不要背景网格太粗：如果需要网格，用浅色细线
4. 不要每张图都换风格：整篇论文的字体、尺寸、配色应统一
5. 不要截图：用 savefig，300 dpi 或 PDF 矢量图
6. 不要为显得丰富而堆图：每张图都要回答一个明确问题

可加轻网格：

```python
ax.grid(axis="y", alpha=0.2)
```

## 3.5 英文图注的常用表达

| 中文意思 | 英文 |
|---|---|
| 历年平均分 | Average score by year |
| 各学校平均分比较 | Comparison of average scores by school |
| 得分与学习时长的关系 | Score versus preparation hours |
| 队伍数 | Number of teams |
| 分数（分） | Score (points) |
| 学习时长（小时） | Preparation hours (h) |
| 占比（%） | Proportion (%) |

标题用 sentence case：首单词大写，其余不必每个单词都大写。
