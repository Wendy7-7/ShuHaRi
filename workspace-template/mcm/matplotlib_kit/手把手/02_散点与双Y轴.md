## 2.1 散点图：两个变量有没有关系

数据 `mcm/matplotlib_kit/data/score_hours.csv` 有 12 支队伍的得分与学习时长。
**注意：这是教学用的小数据，不是证明"学习越久分越高"的真实研究。**

新建 `scatter_chart.py`：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("mcm/matplotlib_kit/data/score_hours.csv")

fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(df["hours"], df["score"], label="Teams")

ax.set_title("Score versus preparation hours")
ax.set_xlabel("Preparation hours (h)")
ax.set_ylabel("Score (points)")
ax.set_xlim(0, 18)
ax.set_ylim(0, 100)
ax.legend()

fig.tight_layout()
fig.savefig("figures/hours_scatter.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

每个点是一支队伍：横坐标学习时长，纵坐标得分。
整体向右上倾斜，说明这份数据里二者呈正相关趋势。

### 按类别给点上色

```python
colors = {"IME": "tab:blue", "SAT": "tab:orange", "BUS": "tab:green"}

for college, group in df.groupby("college"):
    ax.scatter(
        group["hours"], group["score"],
        label=college, color=colors[college]
    )
ax.legend()
```

这段代码的意思：按学院分组，每组单独画一次散点，并给不同颜色。
**`groupby` 不只用于汇总，也可以用于分组画图。**

### 不要在论文里乱写因果

散点图只能说明"有关联"，不能证明"学习时长导致高分"。
也可能原本基础好的队伍既愿意多练、又容易得高分。

论文写法：

> The scatter plot suggests a positive association between preparation hours
> and scores in this small sample; it does not establish causality.

## 2.2 双 Y 轴：两种量纲放在一起

平均分的单位是"分"，队伍数的单位是"队"。
如果把它们画在同一个 Y 轴上，数值意义会混乱，所以用左右两个轴。

新建 `twinx_chart.py`：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("mcm/matplotlib_kit/data/year_trend.csv")

fig, ax1 = plt.subplots(figsize=(7, 4))

ax1.plot(
    df["year"], df["avg_score"],
    color="tab:blue", marker="o", label="Average score"
)
ax1.set_xlabel("Year")
ax1.set_ylabel("Average score (points)", color="tab:blue")
ax1.tick_params(axis="y", labelcolor="tab:blue")
ax1.set_xticks(df["year"])
ax1.set_ylim(0, 100)

ax2 = ax1.twinx()
ax2.bar(
    df["year"], df["teams"],
    color="tab:orange", alpha=0.35, label="Teams"
)
ax2.set_ylabel("Number of teams", color="tab:orange")
ax2.tick_params(axis="y", labelcolor="tab:orange")
ax2.set_ylim(0, 8)

lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc="best")

ax1.set_title("Average score and team count by year")
fig.tight_layout()
fig.savefig("figures/year_twinx.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

## 2.3 双轴代码逐段理解

```python
ax2 = ax1.twinx()
```

创建与 ax1 共用 X 轴、但使用右侧 Y 轴的新绘图区。

```python
alpha=0.35
```

柱子的透明度。让橙色柱子不遮住蓝色折线。

```python
tick_params(axis="y", labelcolor=...)
```

让轴刻度颜色和对应数据颜色一致，读者更容易分左右轴。

```python
get_legend_handles_labels()
```

双轴最常见的坑：只写 `ax1.legend()`，另一个系列不见了。
要分别取出两个轴的图例，再合并。

## 2.4 双 Y 轴的诚实性问题

双轴很容易制造假象：把右边柱子范围调一调，两条线就会看起来"高度相关"。
所以本练习要求：

1. 左轴写清 `points`，右轴写清 `teams`
2. 左右轴用不同颜色并带图例
3. 不用双轴暗示因果
4. 能拆成两张图讲清楚时，优先拆成两张图

**双轴是工具，不是让普通数据显得"有故事"的特效。**
