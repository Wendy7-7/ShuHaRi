# 第 4 课：存图与一键复现（Day 4）

## 4.1 PNG 还是 PDF

| 格式 | 用途 | 优点 |
|---|---|---|
| PNG | 预览、插入 Word、网页 | 通用，300 dpi 后清晰 |
| PDF | 插入 LaTeX 论文 | 矢量，放大不失真 |

同一张图可以同时保存：

```python
fig.savefig("figures/school_bar.png", dpi=300, bbox_inches="tight")
fig.savefig("figures/school_bar.pdf", bbox_inches="tight")
plt.close(fig)
```

PDF 不需要 dpi，因为它保存的是矢量线条而不是像素点。

## 4.2 图片尺寸和论文版心

`figsize=(7,4)` 表示 7 英寸宽、4 英寸高，不是像素。
如果图被字挤满，不要只调 dpi，应该：

1. 增大 figsize
2. 缩短标签
3. 减少无意义刻度
4. 必要时旋转类别名称

```python
ax.tick_params(axis="x", rotation=30)
```

旋转是为了读清长标签，不是为了制造设计感。

## 4.3 文件名要有意义

不推荐：

```text
1.png、新建文件.png、最终版2.png、最终最终版.png
```

推荐：

```text
year_line.png
school_bar.png
hours_scatter.png
year_twinx.png
```

文件名本身就是论文素材管理的一部分。

## 4.4 一键出全部图

新建 `plot_all.py`，把每种图写成一个函数：

```python
from pathlib import Path
import pandas as pd
import matplotlib.pyplot as plt

OUT = Path("figures")
OUT.mkdir(exist_ok=True)


def save(fig, name):
    fig.tight_layout()
    fig.savefig(OUT / f"{name}.png", dpi=300, bbox_inches="tight")
    fig.savefig(OUT / f"{name}.pdf", bbox_inches="tight")
    plt.close(fig)
    print(f"saved: {name}")


def plot_year_line():
    df = pd.read_csv("data/year_trend.csv")
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.plot(df["year"], df["avg_score"], marker="o", label="Average score")
    ax.set_title("Average score by year")
    ax.set_xlabel("Year")
    ax.set_ylabel("Average score (points)")
    ax.set_xticks(df["year"])
    ax.set_ylim(0, 100)
    ax.legend()
    save(fig, "year_line")


def plot_school_bar():
    df = pd.read_csv("data/school_summary.csv")
    df = df.sort_values("avg_score", ascending=False)
    labels = df["school"] + " (n=" + df["teams"].astype(str) + ")"

    fig, ax = plt.subplots(figsize=(7, 4))
    bars = ax.bar(labels, df["avg_score"], label="Average score")
    ax.set_title("Average score by school")
    ax.set_xlabel("School")
    ax.set_ylabel("Average score (points)")
    ax.set_ylim(0, 100)
    ax.bar_label(bars, fmt="%.2f")
    ax.legend()
    save(fig, "school_bar")


if __name__ == "__main__":
    plot_year_line()
    plot_school_bar()
```

### 这段代码的三个好处

- `OUT.mkdir(exist_ok=True)`：没有 figures 文件夹也能运行
- `save()` 统一保存：不会某张图忘了 300 dpi
- 每种图一个函数：改一张图不影响其他图

## 4.5 验证可复现

1. 删除 `figures/` 下所有 PNG 和 PDF
2. 运行 `python plot_all.py`
3. 检查文件是否重新生成
4. 用 Pillow 检查尺寸与 dpi：

```python
from PIL import Image
im = Image.open("figures/year_line.png")
print(im.size)
print(im.info.get("dpi"))
```

尺寸不完全相同没关系，dpi 应接近 300。
