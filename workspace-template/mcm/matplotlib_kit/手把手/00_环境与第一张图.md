目标：跑通环境，理解一张图的组成，并保存出第一张 PNG。

## 0.2 先写第一张图

进入 `matplotlib_kit` 目录，新建 `first_plot.py`：

```python
import matplotlib.pyplot as plt

x = [2024, 2025, 2026]
y = [81.0, 81.2, 76.0]

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(x, y, marker="o")

ax.set_title("Average score by year")
ax.set_xlabel("Year")
ax.set_ylabel("Average score (points)")
ax.set_xticks(x)

fig.tight_layout()
fig.savefig("figures/first_plot.png", dpi=300, bbox_inches="tight")
plt.close(fig)
```

先手动新建 `figures` 文件夹，再运行：

```bash
python first_plot.py
```

打开 `figures/first_plot.png`，你应该看到一条三个点的折线：
2024 年 81.0，2025 年 81.2，2026 年 76.0。

## 0.3 逐行理解

```python
import matplotlib.pyplot as plt
```

搬来绘图工具箱，习惯起名叫 `plt`。

```python
fig, ax = plt.subplots(figsize=(7, 4))
```

创建一张画布和一块绘图区，宽 7 英寸、高 4 英寸。

- `fig`（Figure）：整张图，包括标题、边距、图例等
- `ax`（Axes）：真正画线和柱子的那块区域

后面大多数方法都写在 `ax` 上；保存图片写在 `fig` 上。

```python
ax.plot(x, y, marker="o")
```

画折线，`marker="o"` 表示每个数据点再画一个圆点。
只有三个点时，没有圆点会很难看清数据究竟在哪。

```python
ax.set_xticks(x)
```

年份只显示 2024、2025、2026。不加这句，自动刻度可能出现 2024.5——年份没有"2024.5 年"。

```python
fig.tight_layout()
```

自动调整边距，减少标题和轴标签被挤出去的概率。

```python
fig.savefig(..., dpi=300, bbox_inches="tight")
```

- `dpi=300`：论文打印用的基本清晰度
- `bbox_inches="tight"`：保存时把外侧标题和图例也完整包进去

```python
plt.close(fig)
```

关闭这张图。批量画很多图时不关闭，会越用越占内存。

## 0.4 为什么不教你 plt.show()

`plt.show()` 会弹一个窗口，但它在某些编辑器、远程环境和自动运行脚本里表现不一致。
**论文需要的是图片文件，不是弹窗。** 所以本课程统一：

> 写脚本 → 运行 → 到 figures/ 打开 PNG 检查。

这也更方便一键重跑。

## 0.5 故意踩三个坑

分别做三次小实验，每次改完运行、观察，再改回来：

1. 删除 `ax.set_ylabel(...)`：看 Y 轴是不是立刻变得难以理解
2. 删除 `bbox_inches="tight"`：看外侧内容是否可能被裁切
3. 把 `dpi=300` 改成 `dpi=30`：放大图片，观察锯齿

目的：让你理解这些参数不是装饰。
