# matplotlib 速查表

```python
import pandas as pd
import matplotlib.pyplot as plt

# ---------- 折线 ----------
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(df["year"], df["avg_score"], marker="o", label="Average score")
ax.set_title("Average score by year")
ax.set_xlabel("Year")
ax.set_ylabel("Average score (points)")
ax.set_xticks(df["year"])                 # 年份不要显示成 2024.5
ax.legend()
fig.tight_layout()
fig.savefig("figures/line.png", dpi=300, bbox_inches="tight")
plt.close(fig)

# ---------- 柱状 ----------
fig, ax = plt.subplots(figsize=(7, 4))
ax.bar(df["school"], df["avg_score"], label="Average score")
ax.set_title("Average score by school")
ax.set_xlabel("School")
ax.set_ylabel("Average score (points)")
ax.bar_label(ax.containers[0], fmt="%.2f") # 柱顶标数值
fig.tight_layout()
fig.savefig("figures/bar.png", dpi=300, bbox_inches="tight")
plt.close(fig)

# ---------- 散点 ----------
fig, ax = plt.subplots(figsize=(7, 4))
ax.scatter(df["hours"], df["score"], label="Teams")
ax.set_title("Score versus preparation hours")
ax.set_xlabel("Preparation hours (h)")
ax.set_ylabel("Score (points)")
ax.legend()
fig.tight_layout()
fig.savefig("figures/scatter.png", dpi=300, bbox_inches="tight")
plt.close(fig)

# ---------- 双 Y 轴 ----------
fig, ax1 = plt.subplots(figsize=(7, 4))
ax1.plot(df["year"], df["avg_score"], color="tab:blue", marker="o", label="Average score")
ax1.set_xlabel("Year")
ax1.set_ylabel("Average score (points)", color="tab:blue")
ax1.tick_params(axis="y", labelcolor="tab:blue")
ax1.set_xticks(df["year"])

ax2 = ax1.twinx()
ax2.bar(df["year"], df["teams"], color="tab:orange", alpha=0.35, label="Teams")
ax2.set_ylabel("Number of teams", color="tab:orange")
ax2.tick_params(axis="y", labelcolor="tab:orange")

lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc="best")
ax1.set_title("Average score and team count by year")
fig.tight_layout()
fig.savefig("figures/twinx.png", dpi=300, bbox_inches="tight")
plt.close(fig)

# ---------- 标注 ----------
ax.annotate(
    "Highest: 95 points",
    xy=(2024, 95),                 # 箭头指向的数据点
    xytext=(2024.2, 88),           # 文字位置
    arrowprops={"arrowstyle": "->"}
)
ax.axhline(80, linestyle="--", linewidth=1, label="80-point reference")

# ---------- 导出 ----------
fig.savefig("figures/out.png", dpi=300, bbox_inches="tight")
fig.savefig("figures/out.pdf", bbox_inches="tight")  # 矢量图，LaTeX 优先
plt.close(fig)                                      # 批量画图时释放内存
```

## 报错急救

| 现象 | 原因与处理 |
|---|---|
| 中文变成方框 | 本课程统一用英文图注；论文也用英文，不必折腾中文字体 |
| 保存后标题/图例被裁掉 | 加 `bbox_inches="tight"`，保存前 `tight_layout()` |
| 图例不显示 | 绘图时加 `label=`，之后再 `legend()` |
| 双轴图例只剩一个 | 分别取 `get_legend_handles_labels()` 后合并 |
| 年份变成 2024.5 | `set_xticks(df["year"])` |
| 图片模糊 | `dpi=300`；不要用截图代替保存 |
| 运行后不弹窗 | 本课程用 savefig，不依赖 show；去 figures/ 看文件 |
