# matplotlib 开放任务

前面的练习已经告诉你图型，这次只给问题。美赛里你需要自己决定怎么展示。

## 任务

使用 `data/` 下的练习数据，制作三张图分别回答：

1. **哪所学校表现最好？**
   你可以选择平均分、最高分或其他指标，但必须说明为什么。
2. **历年水平是否发生了明显变化？**
   可以选择折线、柱状或双轴，但必须考虑队伍数量变化。
3. **学习时长和得分是什么关系？**
   用一张图支持你的判断，并写出不能从图中得到什么结论。

## 交付

- 一个 `open_task.py`，运行后生成三张 PNG 和对应 PDF
- 每张图下方写 2–3 句英文分析，包含至少一个数字
- 单独写一句：哪张图最容易误导读者，你做了什么来降低误导

## 自评表

| 维度 | 合格标准 |
|---|---|
| 图型选择 | 能解释为什么选这种图，而不是因为教程画过 |
| 可读性 | 标题、轴名、单位、图例、标注完整 |
| 诚实性 | 坐标范围与样本量不制造夸张结论 |
| 分析 | 有数字、有判断、有局限，不写空洞结论 |
| 复现 | 删除 figures 后一键重建 |

## 提醒

"XJTLU 第一"和"XJTLU 在这 7 支队伍里平均分最高"不是同一句话。
后者才是这份数据真正支持的结论。
