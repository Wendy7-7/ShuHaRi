# matplotlib 学习套件（美赛 2027 备赛 · 第 2 关）

前置：已完成 pandas 第 1 关，能读 CSV、筛选、groupby。
目标：独立做出可以直接放进英文论文的图，不是"能显示就算完"。

## 一、范围

只学：折线图、柱状图、散点图、双 Y 轴、标注、保存图片。
不学：seaborn、3D 图、交互图表、GUI、动画、复杂配色系统。

## 三、环境

```bash
python -m pip install matplotlib pillow
```

所有脚本都在 `matplotlib_kit/` 目录下运行，输出统一写入 `figures/`。
本课程不依赖弹窗：用 `plt.savefig()` 保存后用图片查看器打开。

## 四、论文图的最低标准

每张图必须同时有：

1. 标题（说明图的内容，不写 "Figure 1" 当标题）
2. X/Y 轴名称与单位
3. 多系列时的图例
4. 合适的尺寸和 300 dpi
5. 正文里有一句"这张图说明什么"
