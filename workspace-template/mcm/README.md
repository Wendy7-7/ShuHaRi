## 这个模块怎么用

1. **先读教程**：左侧文件树展开 `mcm/pandas_kit/`，从 `README.md` 和手把手教程看起。
2. **再做题**：顶栏「题库练习」→ 语言下拉选 **pandas（美赛）**，按 Day 1 → Day 10 顺序做。
   每道题都有分级提示（先反问、再给方法、最后给片段），实在卡住再点「看题解」。
3. **数据集就在你电脑里**：`mcm/pandas_kit/data/`。题目里的相对路径 `mcm/pandas_kit/data/xxx.csv`
   在编辑器「▶ 运行」和「判题」两种场景下都能跑通（判题时会自动复制数据集到沙盒）。
4. **AI 助教已切换为美赛教练**：做 pandas 题时打开 AI 面板，它会按 L1–L4 分级提示引导你，
   范围外的问题（深度学习等）会明确告诉你"先不用学"。

## 这份数据是活的

`level1_contest_raw.csv` 不是干净数据——列名带空格、同校 4 种写法、Score 混着"缺考"、
有重复行、有缺失值。**这正是美赛数据的真实样子**。你的目标不是"跑通代码"，
而是学会一套可复用的清洗流程：列名 → 重复 → 缺失 → 类型 → 统一写法 → 合并防膨胀。
