# pandas 学习套件（美赛 2027 备赛 · 第 1 关）

适用对象：Python 学到函数、没写过项目、没学过概率统计的初学者。
目标：在美赛里独立完成"读入 → 清洗 → 合并 → 汇总 → 导出"这条数据处理链。
不包含：MultiIndex、时序重采样、性能优化、机器学习。这些本次用不上。

## 三、开始前的环境准备（只做一次）

```bash
python -m pip install pandas
```

注意：本机 `pip` 和 `python` 可能不是同一个环境，**必须用 `python -m pip`**。

验证：新建 `test.py`，写入并运行：

```python
import pandas as pd
print(pd.__version__)
df = pd.read_csv("data/level1_contest_raw.csv")
print(df.shape)
```

能打印出版本号和 `(22, 5)` 就说明环境通了。

**运行位置很重要**：所有代码都假设你在 `pandas_kit/` 目录下运行，所以数据路径写的是 `data/xxx.csv`。
如果报 `FileNotFoundError`，九成是你运行的目录不对，不是代码错了。

## 四、怎么学：四遍法

每个方法都走四步，缺一步效果减半：

1. 看一遍（讲义）
2. 照着敲一遍（不许复制粘贴）
3. 合上讲义默写一遍
4. 换个数据或换个条件再做一遍

每次学习 45–60 分钟的结构：
5 分钟默写昨天内容 → 25 分钟当天任务 → 20 分钟换数据复做 → 5 分钟写三行踩坑笔记。
