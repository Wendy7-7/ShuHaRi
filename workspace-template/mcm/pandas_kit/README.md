# pandas 学习套件（美赛 2027 备赛 · 第 1 关）

适用对象：Python 学到函数、没写过项目、没学过概率统计的初学者。
目标：在美赛里独立完成"读入 → 清洗 → 合并 → 汇总 → 导出"这条数据处理链。
不包含：MultiIndex、时序重采样、性能优化、机器学习。这些本次用不上。

本套 CSV 均为教学模拟数据，学校与专业名称不代表真实表现。本模块仅检验 pandas 数据处理与解释能力，不代表统计建模或完整美赛能力。

## 三、开始前的环境准备（只做一次）

**第 1 步：先跑自检**

在工作区根目录执行：

```bash
python mcm/pandas_kit/check_env.py
```

它只读文件、不改任何东西，检查 5 项：Python 版本、pandas、数据文件、当前目录、试读数据。

- 最后一行显示 `环境正常，可以开始 Day 1` → 直接跳到「四、怎么学」
- 某项显示「失败」→ 它会在下面直接写「该敲什么命令修」，照着做，再跑一次

> 在 VS Code 里右键这个文件 → 运行也可以；脚本会自己找到数据位置，不要求你在哪个目录。

**第 2 步：只有自检提示 pandas 未安装时才看这里**

```bash
python -m pip install pandas
```

注意：本机 `pip` 和 `python` 可能不是同一个环境，**必须用 `python -m pip`**。
装完**关掉终端重新打开**，再跑一次自检——不重启终端可能还是旧环境。

**为什么先自检**：`ModuleNotFoundError: No module named 'pandas'`（没装）和 `FileNotFoundError`（目录不对）是初学者最容易卡住的两个报错。自检会一次告诉你是哪一个，不用自己猜。

**运行位置很重要**：本应用的一键运行和判题都把工作区根目录作为当前工作目录，所以数据路径统一写 `mcm/pandas_kit/data/xxx.csv`。在终端手动运行时，也要先进入工作区根目录；如果报 `FileNotFoundError`，先检查当前目录，不是立刻改代码。

## 四、怎么学：四遍法

每个方法都走四步，缺一步效果减半：

1. 看一遍（讲义）
2. 照着敲一遍（不许复制粘贴）
3. 合上讲义默写一遍
4. 换个数据或换个条件再做一遍

每次学习 45–60 分钟的结构：
5 分钟默写昨天内容 → 25 分钟当天任务 → 20 分钟换数据复做 → 5 分钟写三行踩坑笔记。
