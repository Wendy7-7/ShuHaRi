## 第 1 章 读入与体检

### 1.1 read_csv：把文件读成表

**干什么**：把 CSV 读成 DataFrame（可以理解成"带列名的 Excel 表"）。
**美赛用在哪**：赛题给的数据第一步。C 题（数据洞察）整道题从这里开始。

```python
import pandas as pd
df = pd.read_csv("mcm/pandas_kit/data/level1_contest_raw.csv")
```

**坑**
- 路径是相对于"你运行代码时所在的目录"，不是相对于 .py 文件的位置。
- 中文乱码/报错时换编码：`encoding="utf-8-sig"` 或 `encoding="gbk"`。
- 分隔符不是逗号时加 `sep=";"` 或 `sep="\t"`。

### 1.2 体检四件套：shape / columns / head / dtypes

**干什么**：知道这份数据有多大、有哪些列、长什么样、每列是什么类型。
**美赛用在哪**：论文"数据预处理"一节的第一句话就来自这里（"原始数据共 X 行 Y 列，其中…"）。

```python
print(df.shape)      # (22, 5)
print(df.columns)    # 注意：' School ' 两端有空格，这是脏数据的一种
print(df.head())
print(df.dtypes)     # Score 显示 str/object，说明里面混了非数字
```

**坑**：`dtypes` 里某列是 `object` 或 `str`，但内容看着像数字——一定是有脏值混进去了。

### 1.3 isna().sum()：数缺失

```python
print(df.isna().sum())
```

**美赛用在哪**：决定你后面是删行还是填充，也决定论文里怎么交代数据质量。

### 1.4 duplicated / unique / value_counts：找重复和写法不一致

```python
print(df.duplicated().sum())          # 完全重复的行数
print(df[" School "].unique())        # 会发现 'XJTLU'、'xjtlu '、' XJTLU'、'xjtlu' 四种写法
print(df[" School "].value_counts())
```

**美赛用在哪**：合并和分组之前必做。同一个学校被当成三所学校，后面的统计全错。

## 第 2 章 清洗

### 2.1 列名与字符串

```python
df.columns = df.columns.str.strip()                 # 列名去空格
df["School"] = df["School"].str.strip().str.upper() # 内容去空格 + 统一大写
```

**美赛用在哪**：几乎所有真实数据都要过这一关。
**坑**：字符串方法要加 `.str`，直接写 `df["School"].strip()` 会报错。

### 2.2 to_numeric：把文本变数字

```python
df["Score_raw"] = df["Score"].copy()
df["Score"] = pd.to_numeric(df["Score_raw"], errors="coerce")
df["Score_status"] = "observed"
df.loc[df["Score_raw"].isna(), "Score_status"] = "unknown"
df.loc[df["Score_raw"].eq("缺考"), "Score_status"] = "absent"
df.loc[df["Score"].isna() & df["Score_raw"].notna() & ~df["Score_raw"].eq("缺考"), "Score_status"] = "parse_error"
```

**干什么**：能转的转成数字，转不了的（比如"缺考"）变成 NaN。
**美赛用在哪**：求均值、画图、回归之前必须做，否则求和会变成字符串拼接。
**坑**：不加 `errors="coerce"` 会直接报错中断；加了之后要重新数一遍缺失，因为缺失变多了。

### 2.3 drop_duplicates：去重

```python
before = len(df)
df = df.drop_duplicates()
print(before, len(df))     # 22 -> 21，差值必须能解释
```

### 2.4 缺失值：删还是填

```python
df = df.dropna(subset=["Year"])                          # 某列缺失就删整行
# 缺考/解析失败不填；unknown 估计参照下节，保留原始观测
df["Members"] = df["Members"].fillna(df["Members"].mode()[0])  # 填众数
```

**美赛用在哪**：这一节直接写进论文，评委看的是你的**理由**，不是代码。

**怎么选（这是重点）**
- 先判断缺失原因和分析任务，再决定保留、回查、排除或估计；不能仅按缺失比例或分布决定填补。
- 本例按年份分析，排除无法推断 Year 的 T10 并报告行数变化；其他任务可以保留它，不能编造年份。
- Score 的 absent/parse_error 保留缺失；仅在明确模拟假设下，unknown 可用原始有效观测均值估计到独立分析列，并标记估计。均值或中位数不会恢复真实分数。
- Members 按众数填 3 仅为模拟练习假设，不是所有类别/计数列的通用策略，也不代表真实赛规。
- **永远不要把缺失当 0**，除非 0 在业务上真的成立（比如"未获奖"记 0 次）。

### 2.5 按分组填充（进阶一点但很常用）

```python
observed = df["Score"].where(df["Score_status"].eq("observed"))
year_means = observed.groupby(df["Year"]).transform("mean")
df["Score_analysis"] = df["Score"].copy()
unknown = df["Score_status"].eq("unknown")
df.loc[unknown, "Score_analysis"] = year_means.loc[unknown]
df["Score_imputed"] = unknown & df["Score_analysis"].notna()
```

**美赛用在哪**：仅为模拟假设：unknown 可按同年原始观测估计，不能保证更合理。缺考和解析失败不填；整组无观测继续缺失。

## 第 3 章 筛选

```python
df[df["Score"] > 80]
df[(df["Year"] == 2026) & (df["School"] == "XJTLU") & (df["Score"] > 80)]
df[df["School"].isin(["XJTLU", "NUAA"])]
df.loc[df["Score"] > 80, ["Team ID", "Score"]]     # 筛行同时只留两列
```

**美赛用在哪**："我们只保留完整记录""重点分析 2026 年的数据"，都是筛选。
**坑**
- 多个条件必须用 `&` / `|`，不能用 `and` / `or`。
- 每个条件必须单独加括号，这是最常犯的语法错。
- 筛选完想改值，用 `.loc`，否则触发 `SettingWithCopyWarning`。

## 第 4 章 合并

```python
scores = pd.read_csv("mcm/pandas_kit/data/level2_scores_raw.csv")
teams = pd.read_csv("mcm/pandas_kit/data/level2_teams_raw.csv")
for d in (scores, teams):
    d["team_id"] = d["team_id"].str.strip().str.upper()

teams = teams.drop_duplicates()
if teams["team_id"].duplicated().any():
    raise ValueError("team_id 存在字段冲突，拒绝静默保留第一条")
merged = scores.merge(teams, on="team_id", how="left", validate="many_to_one")
```

**美赛用在哪**：赛题经常给多个文件（成绩表 + 队伍信息表 + 国家指标表），必须拼起来才能分析。

**how 怎么选**
- `inner`：只留两边都有的键。会丢数据，丢了你必须知道丢了多少。
- `left`：保留左表全部行，右表对不上的填空。**默认优先用它**，因为不会悄悄丢行。

**坑**
- 合并后行数变多 = 键有重复。加 `validate="many_to_one"` 让它直接报错，比事后发现强。
- 两边键的大小写、空格不一致会导致大量对不上，先统一再合并。
- 合并后立刻 `merged.isna().sum()` 检查有没有对不上的行。

## 第 5 章 分组汇总（groupby）

### 5.1 基本形式

```python
merged.groupby("school")["score"].mean()
```

读法：**按学校分组 → 取 score 列 → 求均值**。这就是"分学校比较水平"。

### 5.2 一次算多个指标

```python
merged.groupby("school")["score"].agg(avg_score="mean", teams="count")
```

**美赛用在哪**：论文里的汇总表基本都是这一行出来的。

### 5.3 多键分组、排序、取前几名

```python
merged.groupby(["year", "school"])["score"].mean()
merged.groupby("major")["score"].mean().sort_values(ascending=False).head(5)
```

### 5.4 占比

```python
t = merged.groupby("problem")["score"].count()
print((t / t.sum() * 100).round(1))
```

**美赛用在哪**："62.5% 的队伍选择了 C 题"这类句子。

### 5.5 reset_index

```python
result = merged.groupby("school")["score"].mean().reset_index()
```

**坑**：分组结果的索引是分组的键，不是普通列。后面要画图或导出，先 `reset_index()`。

## 第 6 章 导出与串联

```python
df.to_csv("mcm/pandas_kit/data/level1_clean.csv", index=False, encoding="utf-8-sig")
```

**坑**：不加 `index=False` 会多出一列 `Unnamed: 0`，下次读进来还要再处理一遍。

**pipeline 的意义**：把"读入 → 清洗 → 合并 → 汇总 → 导出"写成一个能一键运行的脚本。
美赛里数据经常会更新或重跑，**手工在 Excel 里改过的步骤无法复现**，代码可以。
你的论文附录里也更需要一个 pipeline，而不是一堆截图。
