## 6.1 筛选的原理（先懂原理，再记写法）

```python
df["Score"] > 80
```

这行**不是筛选**，它得到的是一排 True/False：

```
0     True
1    False
2    False
3     True
...
Name: Score, dtype: bool
```

把这排 True/False 塞回方括号里，才是筛选：

```python
df[df["Score"] > 80]
```

读作：**"从 df 里，只保留 Score > 80 为 True 的那些行"**。

```python
picked = df[df["Score"] > 80]
print(len(picked))     # 看看挑出来几行
print(picked.head())
```

---

## 6.2 单条件筛选的几种常用形式

```python
df[df["Score"] > 80]              # 大于
df[df["Score"] >= 80]             # 大于等于
df[df["School"] == "XJTLU"]       # 等于（文本要加引号）
df[df["School"] != "XJTLU"]       # 不等于
df[df["Year"] == 2026]            # 数字不用引号
df[df["Score"].isna()]            # 挑出缺失的（清洗前用）
df[df["Score"].between(70, 90)]   # 70 到 90 之间，含两端
df[df["School"].isin(["XJTLU", "NUAA"])]   # 属于某几个值之一
```

**`==` 和 `=` 别搞混**：筛选里永远是 `==`。

---

## 6.3 多条件筛选（新手最容易写错的地方）

```python
df[(df["Year"] == 2026) & (df["School"] == "XJTLU") & (df["Score"] > 80)]
```

**实际输出（清洗后的数据）：**

```
    Team ID School    Year  Score  Members
12      T13  XJTLU  2026.0   95.0      3.0
18      T19  XJTLU  2026.0   84.0      3.0
```

### 三条铁律

1. **并且用 `&`，或者用 `|`**，不能用 `and` / `or`
2. **每个条件必须用括号包起来**
3. 条件多了可以拆开写，可读性更好：

```python
cond_year = df["Year"] == 2026
cond_school = df["School"] == "XJTLU"
cond_score = df["Score"] > 80

picked = df[cond_year & cond_school & cond_score]
```

**"非"用 `~`**：

```python
df[~(df["School"] == "XJTLU")]     # 不是 XJTLU 的
```

### 错误示范对照

```python
# 错：用了 and
df[(df["Year"] == 2026) and (df["Score"] > 80)]

# 错：没加括号（& 的优先级比 > 高，会先算 2026 & df["Score"]）
df[df["Year"] == 2026 & df["Score"] > 80]
```

这两个报错信息都很晦涩，看到 `ValueError: The truth value of a Series is ambiguous`
或者莫名其妙的 `TypeError`，先检查这两条。

## 6.4 筛选的同时只保留几列：.loc

```python
df.loc[df["Score"] > 80, ["Team ID", "School", "Score"]]
```

`.loc[行条件, 列列表]`，中间用**逗号**分开：
- 逗号前：哪些行
- 逗号后：哪些列

只要某几列、不过滤行：

```python
df.loc[:, ["Team ID", "Score"]]     # 冒号表示"所有行"
df[["Team ID", "Score"]]            # 等价，更常用
```

---

## 6.5 排序

```python
df.sort_values("Score", ascending=False).head()
```

`ascending=False` = 降序（高的在前）。默认是升序。

按两列排：

```python
df.sort_values(["Year", "Score"], ascending=[True, False])
```

取前三名：

```python
top3 = df.sort_values("Score", ascending=False).head(3)
```

## 6.6 导出 CSV

```python
df.to_csv("data/level1_clean.csv", index=False, encoding="utf-8-sig")
```

三个参数逐个说：

| 参数 | 作用 | 不加会怎样 |
|---|---|---|
| `"data/level1_clean.csv"` | 存到哪 | 必填 |
| `index=False` | **不要保存行号** | 多出一列 `Unnamed: 0` |
| `encoding="utf-8-sig"` | 让 Excel 正确识别中文 | Excel 打开可能乱码 |

### 验证导出是否成功（别省略）

```python
check = pd.read_csv("data/level1_clean.csv")
print(check.shape)
print(check.columns)
```

看到 `(20, 5)`，列名里没有 `Unnamed: 0`，才算真的成功。

## 6.7 为什么不用 Excel 手工改？

因为**不可复现**。

比赛里常见的情况：第三天发现原始数据用错了版本，需要重来。
- 用代码：改一个文件名，运行一次，30 秒全部重来
- 用 Excel：你还得回忆两天前点过的 47 个操作

**你的每一个处理步骤都必须能一键重跑。** 这也是第 9 课 pipeline 的意义。
