## 0.1 你要搞清楚的三个东西

| 名词 | 它是什么 | 类比 |
|---|---|---|
| Python | 读懂并执行你代码的程序 | 播放器 |
| `.py` 文件 | 你写的代码，纯文本 | 视频文件 |

**重要：不要用 Word 或 WPS 写代码。** 它们会自动把直引号 `"` 变成弯引号 `"`，代码直接报废。

## 0.2 全英文输入法（新手第一大坑）

Python 只认**英文符号**。下面这几对，左边能用，右边不能用：

| 正确（英文） | 错误（中文） |
|---|---|
| `(` `)` | `（` `）` |
| `,` | `，` |
| `"` 或 `'` | `"` `"` `'` |
| `:` | `：` |
| `.` | `。` |
| `=` | `＝` |

报错信息里如果出现 `SyntaxError: invalid syntax` 或者 `invalid character`，先检查这一行有没有中文符号。

## 0.4 安装 pandas

在终端里输入：

```bash
python -m pip install pandas
```

**为什么要写 `python -m pip` 而不是 `pip`？**
因为你电脑上可能装了不止一个 Python。直接敲 `pip`，有可能把包装到 A 环境，而你运行代码用的是 B 环境——结果就是"明明装过了，还是说没有"。`python -m pip` 保证"给当前这个 Python 装"。

装完验证：

```bash
python -c "import pandas as pd; print(pd.__version__)"
```

屏幕上出现版本号（例如 `3.1.1`）就成功了。你的版本号不一样完全正常，不用追求一致。

## 0.6 屏幕输出读法

```python
print("hello")     # 让屏幕显示内容，括号里是什么就显示什么
```

- `print(df.shape)` → `(22, 5)`，22 行 5 列
- `print(df)` → 打印整张表，行多的时候会自动省略中间
- `print(df.head())` → 只看前 5 行，**最常用**

**新手铁律：写完两三行就 print 一次。** 不要憋五十行再运行，出了错你根本不知道错在哪。

## 0.7 报错怎么办

报错长这样：

```
Traceback (most recent call last):
  File "test.py", line 3, in <module>
    df = pd.read_csv("mcm/pandas_kit/data/level1_contest_raw.csv")
FileNotFoundError: [Errno 2] No such file or directory: 'mcm/pandas_kit/data/level1_contest_raw.csv'
```

**只看最后两行**：第几行、什么错。前面那一大堆是 Python 内部的调用过程，与你无关。

| 报错关键词 | 意思 | 怎么办 |
|---|---|---|
| `FileNotFoundError` | 文件没找到 | 检查工作目录、文件名拼写 |
| `ModuleNotFoundError` | 没装这个库 | `python -m pip install 库名` |
| `SyntaxError` | 语法写错 | 查中文符号、括号是否成对 |
| `KeyError` | 列名不存在 | `print(df.columns)` 看真实列名 |
| `NameError` | 变量没定义 | 是不是少运行了前面某行，或拼错了变量名 |
