## 2.1 先看一眼原始文件

用 VS Code 打开 `data/level1_contest_raw.csv`，你会看到：

```
Team ID, School ,Year,Score,Members
T01,XJTLU,2024,88,3
T02,XJTLU,2024,76,3
T03,xjtlu ,2024,,2
...
```

**CSV 就是"用逗号分隔的纯文本表格"**。第一行是列名，后面每行是一条记录。

先看三个地方（这是故意埋的坑）：
- 第二行列名是 ` School `，**两端有空格**
- T03 那行的 School 是 `xjtlu `，小写还带空格
- T03 那行 Score 是空的（两个逗号之间什么都没有）

---

## 2.2 写第一段代码

新建文件 `my_day1.py`，输入（**手敲，不要复制**）：

```python
import pandas as pd

df = pd.read_csv("data/level1_contest_raw.csv")

print(df.shape)
```

运行：

```bash
python my_day1.py
```

**屏幕上应该出现：**

```
(22, 5)
```

意思是 22 行、5 列。如果出现了，恭喜你，数据已经读进来了。

### 逐行解释

| 代码 | 含义 |
|---|---|
| `import pandas as pd` | 搬来 pandas 工具箱，起短名叫 pd |
| `df = pd.read_csv(...)` | 用 read_csv 读文件，结果起名叫 df |
| `"data/level1_contest_raw.csv"` | 文件位置：当前目录下的 data 文件夹里 |
| `print(df.shape)` | 打印这张表的形状（行数, 列数） |

**`df` 是什么？** DataFrame 的缩写，你可以理解成"Python 里的一张 Excel 表"。起名叫 `df`、`data`、`table` 都可以，`df` 是大家的习惯。

## 2.3 看看表长什么样

在代码后面加两行，保存，再运行：

```python
print(df.head())
print(df.columns)
```

`head()` = 显示前 5 行。想看前 3 行就写 `head(3)`：

```
  Team ID  School     Year Score  Members
0     T01    XJTLU  2024.0    88      3.0
1     T02    XJTLU  2024.0    76      3.0
2     T03   xjtlu   2024.0   NaN      2.0
```

注意三件事：
1. **最左边那列 0、1、2 是"行号"（索引），不是数据**。它是 pandas 自动加的。
2. **`NaN`** = Not a Number，这里表示**缺失**，就是原文件里那个空格子。
3. `Year` 显示成 `2024.0` 而不是 `2024`，因为这一列里有缺失，pandas 只能把它当小数处理。

`columns` 的输出：

```
['Team ID', ' School ', 'Year', 'Score', 'Members']
```

看到 `' School '` 了吗？**列名里真的带空格**。这意味着：

```python
df["School"]      # 会报错 KeyError: 'School'
df[" School "]    # 这样才能取到
```

## 2.4 取出一列

```python
print(df["Score"])
```

输出是一整列，带行号：

```
0       88
1       76
2      NaN
3       91
4      缺考
...
```

想看成普通列表：

```python
print(df["Score"].tolist())
```

```
['88', '76', nan, '91', '缺考', '83', ...]
```

**注意：`'88'` 是带引号的，说明它是文本，不是数字。** 这就是 Score 列的问题所在。

---

## 2.5 取出多列

**要套两层方括号**，这是新手必踩的坑：

```python
print(df[["Team ID", "Score"]].head())
```

理解方式：外层 `df[...]` 表示"我要取列"，里面 `["Team ID", "Score"]` 是一个**列表**（第 1 课学过的），表示"要这几列"。

---

## 2.6 取出某一行

```python
print(df.loc[0])        # 第 0 行（第一条记录）
print(df.loc[0, "Score"])   # 第 0 行的 Score
```

`.loc[行, 列]` 是按"名字"取，后面筛选时还会大量用到它。

## 2.8 本课最容易犯的 5 个错

| 错误 | 现象 | 解决 |
|---|---|---|
| 忘了保存文件 | 运行结果没变 | `Ctrl + S` |
| 工作目录不对 | `FileNotFoundError` | `cd` 到 `pandas_kit` |
| 中文引号/逗号 | `SyntaxError` | 切英文输入法重打 |
| `df[School]` 没加引号 | `NameError` | 列名是文本，必须 `df["School"]` |
| 取多列只写一层括号 | `KeyError` | `df[["A", "B"]]` |
