## 3.1 每列是什么类型：dtypes

```python
print(df.dtypes)
```

**实际输出：**

```
Team ID         str
 School         str
Year        float64
Score           str
Members     float64
dtype: object
```

逐个翻译：

| 显示 | 意思 |
|---|---|
| `str` / `object` | 文本列 |
| `float64` | 小数列（有缺失的整数也会变成这个） |
| `int64` | 整数列 |
| `bool` | 真假列 |

**重点看 Score：它是 `str`，但它明明应该是分数。**
结论：这列里混进了非数字的东西。（第 2 课我们已经看到了"缺考"。）

> 你机器上如果显示 `object` 而不是 `str`，是版本差异，含义一样，不用管。

## 3.2 一次性看全貌：info()

```python
df.info()
```

它会告诉你：有多少行、每列叫什么、**有多少个非空值**、什么类型。

**"非空数量"比"缺失数量"更直观**：22 行的表里，某列只有 21 个非空，就说明缺了 1 个。

## 3.3 数缺失：isna().sum()

```python
print(df.isna().sum())
```

**实际输出：**

```
Team ID     0
 School     0
Year        1
Score       2
Members     1
dtype: int64
```

### 这行代码是怎么工作的（拆开看）

```python
df.isna()          # 得到一张同样大小的表，每个格子里是 True/False：是不是缺失
df.isna().sum()    # 对每一列求和，True 算 1，False 算 0 → 每列缺了几个
```

**这是 pandas 的典型套路：一个方法返回一张新表，你可以接着再点一个方法。**

现在你知道了：Year 缺 1、Score 缺 2、Members 缺 1。**先别急着填**，下一课再处理。

## 3.5 找重复行：duplicated()

```python
print(df.duplicated().sum())      # 1
```

意思是：**有 1 行和前面的某一行完全一样**。

把重复的行显示出来：

```python
print(df[df.duplicated(keep=False)])
```

`keep=False` 的意思是"重复的双方都要显示"，这样你能看到是哪两条。

> `df[df.duplicated()]` 这种写法读作："从 df 里，挑出 duplicated 为 True 的那些行"。
> 方括号里放一堆 True/False，pandas 就只保留 True 对应的行。这是**筛选**的原理，第 6 课会详细用。

**还可以只按某一列查重复：**

```python
print(df.duplicated(subset="Team ID").sum())
```

即"队伍编号重复的有几条"。

## 3.6 找写法不一致：unique() 和 value_counts()

```python
print(df[" School "].unique())
```

**实际输出：**

```
['XJTLU', 'xjtlu ', 'NUAA', ' XJTLU', 'HIT', 'SJTU', 'xjtlu']
```

数一数，XJTLU 出现了几种写法？

- `'XJTLU'` —— 正常
- `'xjtlu '` —— 小写 + 尾部空格
- `' XJTLU'` —— 前面有空格
- `'xjtlu'` —— 全小写

**四种写法，其实是同一所学校。**

再数一数各出现几次：

```python
print(df[" School "].value_counts())
```

```
XJTLU     6
NUAA      5
HIT       4
SJTU      4
xjtlu     1
 XJTLU    1
xjtlu     1
```

XJTLU 被拆成了 6 + 1 + 1 + 1 = 9 条。

### 为什么这事很严重

如果你现在直接按学校分组求平均，pandas 会把它们当成**四个不同的学校**。
结果：XJTLU 的平均分被算成四个小样本的平均，完全失真。
**清洗必须先于统计，这就是原因。**
