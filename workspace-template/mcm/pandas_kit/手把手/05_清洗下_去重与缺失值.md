## 5.1 去重

```python
before = len(df)
df = df.drop_duplicates()

```

全列重复与键重复不同。同一 Team ID 的其他字段可能冲突；必须展示并核实冲突，不得按键静默保留第一条。合并右表仅删除全列重复，再验证键唯一。

## 5.2 保留原始值与语义

转换 Score 前先保留 Score_raw，数值列叫 Score，另记 Score_status：observed 为有效观测，unknown 为原始空值，absent 为缺考（验收数据是未提交），parse_error 为其他非空字符串解析失败。后三种情况转换后都可能为 NaN，但含义不同。缺考和解析失败不得盲填均值或零。

```python
df["Score_raw"] = df["Score"].copy()
df["Score"] = pd.to_numeric(df["Score_raw"], errors="coerce")
df["Score_status"] = "observed"
df.loc[df["Score_raw"].isna(), "Score_status"] = "unknown"
df.loc[df["Score_raw"].eq("缺考"), "Score_status"] = "absent"
df.loc[df["Score"].isna() & df["Score_raw"].notna() & ~df["Score_raw"].eq("缺考"), "Score_status"] = "parse_error"
```

以上代码应在第4课转换处执行一次，已转换后的 Score 不能当成原值重做。本课按年份分析，排除无法可靠推断年份的 T10（原记录保留在原始CSV中），得到20行；这不是所有任务必须采用的策略。

```python
df = df.dropna(subset=["Year"])
```

## 5.3 可选：只填 unknown，使用原始观测均值

```python
observed = df["Score"].where(df["Score_status"].eq("observed"))
year_means = observed.groupby(df["Year"]).transform("mean")
df["Score_analysis"] = df["Score"].copy()
unknown = df["Score_status"].eq("unknown")
df.loc[unknown, "Score_analysis"] = year_means.loc[unknown]
df["Score_imputed"] = unknown & df["Score_analysis"].notna()
```

这是模拟教学假设，不代表同年份均值一定合理。transform 返回与行对齐的组均值；必须从原始有效观测算均值，而不是再次使用已填补值。组内无观测则继续缺失；估计会降低方差，要同时报告有效观测数和估计数。absent 两行仍缺失，parse_error 需回查原值。

## 5.4 人数与验证

```python
# 可选模拟假设：人数采用众数，不能据众数推出真实赛规。
df["Members"] = df["Members"].fillna(df["Members"].mode().iloc[0])
print(df.shape)  # (20, 9)：原始 5 列 + Score_raw/Score_status + Score_analysis/Score_imputed
print(df[["Score", "Score_analysis"]].isna().sum())  # 4、2；Score 的 4 个缺失含义是 unknown 2 + absent 2
print(df["Score_status"].value_counts())  # observed 16、unknown 2、absent 2
print(df["Score_imputed"].sum())  # 2
df.to_csv("mcm/pandas_kit/data/level1_clean.csv", index=False, encoding="utf-8-sig")
```

mode 返回 Series，可能有并列众数，选择第一项需要解释。传整个 Series 给 fillna 会按索引对齐，可能填错，并不保证报错。

不以所有格子无缺失为目标。保留原始值、原因、估计标记；筛选真实高分继续用 Score，不把估计值当成实测成绩。
