## 5.1 去重

```python
before = len(df)
df = df.drop_duplicates()
after = len(df)
print(f"去重：{before} -> {after}")
```

**输出：**

```
去重：22 -> 21
```

**一定要打印前后行数。** 如果哪天你发现从 22 变成了 8，那一定是哪里写错了，而不是数据真的这么脏。

只看某一列重复才去重（第 7 课合并前要用）：

```python
df = df.drop_duplicates(subset="Team ID")
```

> 注意：`drop_duplicates()` 默认保留**第一次出现**的那一行。
> 想要保留最后一次出现的，加 `keep="last"`。

## 5.2 缺失值处理的总原则

先问三个问题，再决定动手：

1. **缺了多少？** 22 行缺 1 行和缺 15 行，处理方式完全不同。
2. **缺的这个值能推断出来吗？** 能推断才考虑填，不能推断就别编。
3. **这一列是什么性质？** 年份、分数、人数，处理方式都不一样。

| 情况 | 建议 | 理由 |
|---|---|---|
| 缺失很少且无法推断 | 删行 | 编一个值等于造假数据 |
| 数值列，分布比较对称 | 填均值 | 不明显拉高拉低整体 |
| 数值列，有极端值 | 填中位数 | 均值会被极端值带偏 |
| 类别列、计数列 | 填众数 | 出现最多的就是最常见的正常情况 |
| 有明确业务含义的"没有" | 填 0 | 例如"未获奖次数" |
| 成绩"未提交" | **不要填 0** | 未提交 ≠ 考 0 分 |

## 5.3 Year 缺失：删行

```python
print(df[df["Year"].isna()])     # 先看看是谁缺
```

是 T10，只有年份那一格是空的。

```python
# Year 只有 1 行缺失，且无法从其他列推断，删行比编造年份更诚实
df = df.dropna(subset=["Year"])
print(len(df))     # 20
```

`subset=["Year"]` 的意思是"**只看 Year 这一列，它缺了就删整行**"。

**如果写 `df = df.dropna()` 不加 subset**：只要任何一列有缺失就删整行。
在这里会把 Score、Members 缺失的行也一起删掉，数据量直接缩水——**这是新手最容易误删数据的地方**。

## 5.4 Score 缺失：用"同年份的平均分"填

先看朴素做法：

```python
df["Score"] = df["Score"].fillna(df["Score"].mean())
```

能跑，但不够好。因为不同年份整体水平不一样，用全体均值填会扭曲分布。

更好的做法（推荐）：

```python
# 不同年份整体水平不同，用当年均值填充更合理
df["Score"] = df["Score"].fillna(
    df.groupby("Year")["Score"].transform("mean")
)
```

### 这行代码拆开读

- `df.groupby("Year")` —— 按年份分组
- `["Score"]` —— 只看分数
- `.transform("mean")` —— **每一行都返回"它所属那一组的均值"**，长度和原表一样
- `fillna(...)` —— 只把缺失的格子填上，原来有值的不动

`transform` 和 `mean` 的区别：

| 写法 | 返回什么 |
|---|---|
| `groupby("Year")["Score"].mean()` | 每年一行，只有 3 行（汇总表） |
| `groupby("Year")["Score"].transform("mean")` | 每行一个值，还是 20 行 |

**要填回去，必须用 transform。** 用 mean 会因为行数对不上而报错或填错。

## 5.5 Members 缺失：填众数

```python
print(df["Members"].mode())     # 看看众数是什么
```

```python
# 赛规即 3 人一队，众数就是 3，有明确依据
df["Members"] = df["Members"].fillna(df["Members"].mode()[0])
```

**为什么写 `mode()[0]`？**
因为 `mode()` 返回的是一个列表（可能有多个并列众数），`[0]` 取第一个。
直接 `fillna(df["Members"].mode())` 会报错。

## 5.6 最后检查

```python
print(df.isna().sum())
print(df.shape)
```

缺失应该**全是 0**，行数应该是 **20**（22 - 1 重复 - 1 年份缺失）。

```python
print(df.describe())
```

再看一次均值：和填充前比应该变化不大。如果均值剧烈变动，说明你的填充方式有问题。

## 5.8 本课常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| 行数突然变得很少 | `dropna()` 没加 subset | 改成 `dropna(subset=["某列"])` |
| 填充后仍然缺 | 分组里整组都缺，均值也是 NaN | 检查该组是否全空 |
| `TypeError` 出现在 fillna | `mode()` 没加 `[0]` | `mode()[0]` |
| 均值填进去和小数位数很长 | 正常现象 | 需要时 `round(2)`，但**计算前不要四舍五入** |
