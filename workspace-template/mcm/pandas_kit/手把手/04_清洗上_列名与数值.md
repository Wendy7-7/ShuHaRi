## 4.1 第一步：去掉列名的空格

```python
import pandas as pd

df = pd.read_csv("mcm/pandas_kit/data/level1_contest_raw.csv")
print(df.columns)          # 先看原样

df.columns = df.columns.str.strip()
print(df.columns)          # 再看结果
```

**输出：**

```
['Team ID', 'School', 'Year', 'Score', 'Members']
```

### 这行代码为什么长这样

- `df.columns` 是"所有列名"
- `.str` 是"我要对里面的文本做字符串操作"的开关
- `.strip()` 是"去掉两端空格"
- 整体赋值回 `df.columns`，就是把新列名替换掉旧的

**记住 `.str` 这个开关**：对一整列文本做 strip / upper / lower，都要先点 `.str`。
漏了它会报 `AttributeError`，这是新手高频报错。

## 4.2 第二步：统一 School 的写法

现在列名干净了，可以正常写 `df["School"]` 了：

```python
df["School"] = df["School"].str.strip().str.upper()
print(df["School"].unique())
```

**输出：**

```
['XJTLU', 'NUAA', 'HIT', 'SJTU']
```

从 7 种写法变成 4 个真实学校。再数一次：

```python
print(df["School"].value_counts())
```

```
XJTLU    9
NUAA     5
HIT      4
SJTU     4
```

XJTLU 恢复成 9 条，和上一课手算的一致。**清洗是否生效，要用输出验证，不能跑完就当成功了。**

### 链条写法的读法

```python
df["School"].str.strip().str.upper()
#           └── 先去空格 ──┘└── 再转大写 ──┘
```

从左往右依次执行，和上一步的结果接着算，叫**链式调用**。
分两步写也完全等价：

```python
df["School"] = df["School"].str.strip()
df["School"] = df["School"].str.upper()
```

顺手把队伍编号也统一了（第 7 课合并要用）：

```python
df["Team ID"] = df["Team ID"].str.strip().str.upper()
```

## 4.3 第三步：把 Score 变成数字

先看转换前：

```python
print(df["Score"].dtype)     # str / object
print(df["Score"].tolist())  # 能看到 '缺考' 和 nan
```

执行转换：

```python
df["Score_raw"] = df["Score"].copy()
df["Score"] = pd.to_numeric(df["Score_raw"], errors="coerce")
df["Score_status"] = "observed"
df.loc[df["Score_raw"].isna(), "Score_status"] = "unknown"
df.loc[df["Score_raw"].eq("缺考"), "Score_status"] = "absent"
df.loc[df["Score"].isna() & df["Score_raw"].notna() & ~df["Score_raw"].eq("缺考"), "Score_status"] = "parse_error"

print(df["Score"].dtype)          # float64
print(df["Score"].isna().sum())   # 4
```

### 关键问题：缺失为什么从 2 变成 4？

因为原来有 2 个原始空值 + 2 个"缺考"。Score_raw 与 Score_status 分别保留原值和缺失原因。
`errors="coerce"` 的意思是：**"转不了的，别报错，给我变成缺失（NaN）"**。

| 写法 | 遇到"缺考"时的表现 |
|---|---|
| `pd.to_numeric(df["Score"])` | 直接报错，程序中断 |
| `pd.to_numeric(..., errors="coerce")` | "缺考" → NaN，继续运行 |
| `pd.to_numeric(..., errors="raise")` | 明确报错并保留原值供排查 |

Pandas 3.1.1 的 errors 只支持 raise / coerce。coerce 适用于保留原值并记录转换失败的流程，不代表所有 NaN 都能按同一种原因填补。

**转换后必须重新数一遍缺失**，这是固定动作：

```python
print(df.isna().sum())
```

顺手把 Members 也转了：

```python
df["Members"] = pd.to_numeric(df["Members"], errors="coerce")
```

## 4.5 到目前为止你的完整代码

```python
import pandas as pd

df = pd.read_csv("mcm/pandas_kit/data/level1_contest_raw.csv")

# 列名去空格，否则取列会 KeyError
df.columns = df.columns.str.strip()

# 同一所学校有多种写法，统一后才能正确分组
df["School"] = df["School"].str.strip().str.upper()
df["Team ID"] = df["Team ID"].str.strip().str.upper()

# Score 里混了"缺考"，转成数值，无法转换的设为缺失
df["Score_raw"] = df["Score"].copy()
df["Score"] = pd.to_numeric(df["Score_raw"], errors="coerce")
df["Score_status"] = "observed"
df.loc[df["Score_raw"].isna(), "Score_status"] = "unknown"
df.loc[df["Score_raw"].eq("缺考"), "Score_status"] = "absent"
df.loc[df["Score"].isna() & df["Score_raw"].notna() & ~df["Score_raw"].eq("缺考"), "Score_status"] = "parse_error"
df["Members"] = pd.to_numeric(df["Members"], errors="coerce")

print(df.dtypes)
print(df.isna().sum())
print(df.describe())
```

**把这段跑通，第 4 课就过关了。**

## 4.6 本课常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `AttributeError: Can only use .str accessor with...` | 对数值列用了 `.str` | `.str` 只用于文本列 |
| `AttributeError: 'Series' object has no attribute 'strip'` | 忘了加 `.str` | 改成 `.str.strip()` |
| `KeyError: 'School'` | 列名还没去空格 | 先做 4.1 |
| `ValueError: Unable to parse string "缺考"` | to_numeric 没加 coerce | 加 `errors="coerce"` |
