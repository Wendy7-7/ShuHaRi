# pandas 速查表（练习和模块验收均允许查看）

```python
import pandas as pd

# ---------- 读入 ----------
df = pd.read_csv("mcm/pandas_kit/data/xxx.csv")                    # 最基本
pd.read_csv("xxx.csv", encoding="utf-8-sig")         # 中文乱码时试这个
pd.read_csv("xxx.csv", encoding="gbk")               # 老 Excel 导出的中文文件
pd.read_csv("xxx.csv", sep=";")                      # 分隔符不是逗号时

# ---------- 体检 ----------
df.shape                # (行数, 列数)
df.columns              # 列名
df.head()               # 前 5 行
df.dtypes               # 每列类型
df.info()               # 类型 + 非空数量
df.describe()           # 数值列统计：均值、标准差、四分位
df.isna().sum()         # 每列缺失数量
df.duplicated().sum()   # 完全重复的行数
df["School"].unique()   # 某列有哪些不同取值（查写法不一致最好用）
df["School"].value_counts()  # 每个取值出现几次

# ---------- 清洗 ----------
df.columns = df.columns.str.strip()          # 去掉列名两端空格
df["School"] = df["School"].str.strip()      # 去掉内容两端空格
df["School"] = df["School"].str.upper()      # 统一大写
df = df.drop_duplicates()                    # 删完全重复的行
df = df.drop_duplicates()                     # 只删确认的全列重复
df = df.dropna(subset=["Year"])              # 删掉某列缺失的行
# 保留原始值和状态；估计缺失值前先区分 unknown / absent / parse_error
df["Members"] = df["Members"].fillna(df["Members"].mode()[0])  # 填众数

# ---------- 类型 ----------
df["Score"] = pd.to_numeric(df["Score"], errors="coerce")  # 转数值，转不了变 NaN
df["Year"] = df["Year"].astype("Int64")      # 带缺失的整数用这个

# ---------- 筛选 ----------
df[df["Score"] > 80]
df[(df["Year"] == 2026) & (df["School"] == "XJTLU")]     # 与：&  或：|  每个条件加括号
df[df["School"].isin(["XJTLU", "NUAA"])]
df.loc[df["Score"] > 80, ["Team ID", "Score"]]           # 筛选行 + 选列

# ---------- 合并 ----------
pd.merge(a, b, on="team_id", how="left")     # 保留左表全部行
pd.merge(a, b, on="team_id", how="inner")    # 只保留两边都有的
pd.merge(a, b, on="team_id", how="left", validate="many_to_one")  # 键重复会报错，提前暴露问题
pd.concat([a, b])                            # 上下拼接（列结构相同）

# ---------- 分组汇总 ----------
df.groupby("school")["score"].mean()
df.groupby("school")["score"].agg(avg="mean", n="count")   # 多指标
df.groupby(["year", "school"])["score"].mean()             # 多键
df.groupby("school")["score"].mean().sort_values(ascending=False)
df.groupby("school")["score"].mean().reset_index()         # 分组结果变回普通表

# ---------- 导出 ----------
df.to_csv("out.csv", index=False)                        # 必须 index=False
df.to_csv("out.csv", index=False, encoding="utf-8-sig")  # 用 Excel 打开不乱码
```

## 报错急救

| 报错 | 大概率原因 |
|---|---|
| `FileNotFoundError` | 运行目录不对，或文件名拼错 |
| `KeyError: 'xxx'` | 列名不对，先 print(df.columns)，常见是列名带空格 |
| `SettingWithCopyWarning` | 筛选后直接赋值，改用 .loc |
| `UnicodeDecodeError` | 编码不对，换 encoding="gbk" 或 "utf-8-sig" |
| merge 后行数变多 | 检查键重复及字段冲突；仅确认全列重复后去重，再用 validate |
| `can only concatenate str` | 数字被读成文本，先 to_numeric |
