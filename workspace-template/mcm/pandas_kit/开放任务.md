# 开放任务（Day 15 之后、闭卷验收之前做）

前面 15 天的练习都有一个共同点：**步骤已经告诉你了**。
但美赛不会告诉你步骤，它只给你数据和问题。这份任务就是补这个差距。

## 规则

- 不给步骤，自己决定先做什么、后做什么
- 允许看速查表，不允许看参考答案（本任务也没有标准答案）
- 建议用时 60–90 分钟
- 用 `mcm/pandas_kit/data/level1_contest_raw.csv` 和 `mcm/pandas_kit/data/level2_*.csv`，也可以自己另找一份公开 CSV

## 题目

你所在的建模小队拿到一份"历年参赛成绩"数据，需要在论文中回答三个问题：

1. **哪所学校整体表现最好？** 你需要自己决定"整体表现"用什么衡量——平均分？最高分？获奖队伍占比？稳定性？
   选一种并说明理由，再指出这种衡量方式的局限。
2. **不同年份的水平是否有明显变化？** 用数据支持你的说法，不要只写"逐年提高"。
3. **如果只能向教练提一条备赛建议，你会基于数据提什么？**

## 必须交付的东西

1. 一个能一键运行的 `.py`（读入 → 清洗 → 分析 → 输出）
2. 至少两张汇总表
3. 一段 150 字以内的中文分析，或 80 词以内的英文分析
4. 一句话说明：**你的数据有什么局限，导致结论不能推得太远**

## 自评标准

| 维度 | 不合格 | 合格 |
|---|---|---|
| 数据处理 | 直接用了没清洗的数据 | 清洗步骤完整且能解释 |
| 指标选择 | 只说"平均分最高" | 说明了为什么选这个指标及其局限 |
| 结论 | 只有数字没有判断 | 数字 + 判断 + 建议 |
| 样本意识 | 1 支队伍也敢下结论 | 主动报告每组样本量 |
| 可复现 | 有手工改动 | 一键重跑结果一致 |

**"样本意识"那一行最重要。** 真实比赛里，评委扣分最多的不是模型简单，
而是"用 3 个样本得出了关于全世界的结论"。
