# 欢迎使用 LearnPlatform

这里是为**正在学编程的你**准备的工作台：左边看资料，右边写代码，写完立刻知道对不对，卡住了有 AI 助教陪你聊到通为止。

## 第一次用？三步上手

1. **做题**：顶栏「题库练习」→ 选一道题 → 代码写好 → 点「判题」。用例全绿就是通过，做错的题会自动进「错题本」。
2. **跑代码**：打开任意 C/Python 文件，点编辑器上的「▶ 运行」，结果直接显示在下方终端——不用学任何命令。
3. **卡住了**：点「AI 助教」提问。第一次用需要在「设置」里配一个 Key，「帮助」页有手把手的申请教程。

## 日常学习建议

- 看「学习」页的资料 → 去题库练对应的知识点 → 错了进错题本，隔天重做
- 学完一个阶段，来一场「考试模式」自测，检验真实水平
- 顶部「帮助」里有常见报错速查表——看不懂报错就先去那里查

## 好习惯

- 代码写完随手 `Ctrl+S`（不保存的话，判题用的是旧代码）
- 别只看题解，先自己写 10 分钟再求助
- 把「统计」页当成你的进度条：已解决数量、薄弱知识点，都会替你记着
